# Calculadora - Consumo de Energia

O objetivo desse sistema desenvolvido em Python é calcular o gasto e custo mensal de cada aparelho, ele colhe os dados necessários como o tipo de aparelho, potência em watts, tempo de uso diário em horas o valor do KWh.
A fórmula utilizada para chegar em um resultado sobre o gasto e custo mensal por aparelho é:
- Consumo mensal = (Potência * Horas por Dia * 30) /1000

Para calcular o valor gasto por mês, o programa multiplica o valor de consumo mensal com o valor do KWh, com isso, ele exibe o resultado.

# EXECUÇÃO DO PROGRAMA

## VS Code

* Abra o projeto no VS Code
* No canto superior direito, clique no botão " Executar o arquivo do Python "
* Insira os dados solicitados pelo programa e aguarde os resultados.

## Pelo Terminal

* Abra o CMD ou CRTL+J no VS Code
* Ande até a pasta do projeto
* Rode o comando Python
```bash 
cd Consumo-energia
python app.py
```
